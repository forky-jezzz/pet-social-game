# Design System · 宠物社交小游戏

> 本稿为正式视觉与场景规范。实现时以本文为准；旧「仅动森庭院」示意已废止。  
> 气质可借鉴动森室内 /《猫咪后院》的 2.5D 温馨感，**禁止使用任天堂等商业 IP 素材**。

---

## 一、整体美术视觉规范

### 1.1 色彩基调（Color Palette）

| 角色 | 名称 | 色值 |
|------|------|------|
| 主色 | 奶油白 | `#FDFBF7` |
| 主色 | 燕麦奶茶 | `#EFE6D5` |
| 主色 | 日落淡橘 | `#F9D3B4` |
| 辅助 | 牛油果绿 | `#D8E3C5` |
| 辅助 | 柔和天蓝 | `#C9E2F0` |
| 文字/边框 | 深咖啡 | `#5C4033`（禁用纯黑 `#000`） |

语义用法：

- 页面底 / 卡片：奶油白、燕麦奶茶  
- 强调 CTA（喂养/确认）：日落淡橘  
- 自然点缀（植物、成功态）：牛油果绿  
- 信息/链接（聊天、天气）：柔和天蓝  
- 所有正文、描边、图标线：深咖啡  

### 1.2 材质与质感

- **水彩晕染 + 纸张纹理**：背景与插画边缘带轻微水彩纸磨砂噪点。  
- **圆润贴纸 UI**：按钮 / 弹窗 `border-radius ≥ 20px`，轻软阴影（低透明度咖啡影），像可撕贴纸。  
- **动态反馈**：点击 **Q 弹缩放（bounce）** + 气泡弹出音效。  

CSS / Cocos 参考：

```
shadow: 0 6px 16px rgba(92,64,51,0.12)
radius: 20~28
press: scale 0.92 → spring 1.05 → 1.0
```

### 1.3 字体与图标

- 标题：圆润手写感或圆体；正文：清晰无衬线。  
- 图标：线面结合、圆角、贴纸风；禁用尖锐线性图标。

## 二、核心场景结构与 UI 布局

### 场景 1：我的家园（Main Room）—— 核心养殖与展示

**透视**：2.5D 平行视角（类似动森室内 /《猫咪后院》），可见地板、后墙、左/右侧窗。

| 层 | 内容 |
|----|------|
| 背景层 | 可换木地板；落地窗斜射阳光与光斑；窗外随天气变树影/雨滴 |
| 家具层 | 地毯、宠窝、挂墙画框（晒图历史位）、盆栽 |
| 宠物层 | 中心 Spine 宠（换装 + idle：呼吸/眨眼/摇尾） |

**UI（四周悬浮，不挡画面中心）**

| 位置 | 内容 |
|------|------|
| 左上 | 圆头像 + 宠名 + 状态胶囊（心情 / 饥饿图标） |
| 右上 | 信件（红点）、背包/图鉴、设置 |
| 右侧 | 世界聊天入口（气泡缩略）、晒图广场入口 |
| 底部四大动作 | 🥣 喂养 · 👚 换装 · 🚪 串门 · 📸 拍照 |

底部交互细则：

1. **喂养**：弹出横向滑动生鲜食品菜单。  
2. **换装**：抽屉式时尚衣柜面板。  
3. **串门**：展开「好友列表 / 随机拜访」。  
4. **拍照**：一键隐 UI → 动森拍立得风相框 → 可直传晒图广场。  

示意：`docs/refs/scene-01-main-room.png`

---

### 场景 2：串门家园（Visiting Mode）

**视觉微调**

- 顶栏显眼：`[好友名字] 的家` + 「加好友 / 赞」气泡。  
- 双宠同框：主人宠在窝里；访客宠从门口走入（短位移动画）。  

**专属互动**

| 交互 | 表现 |
|------|------|
| 帮打扫 / 帮喂食 | 小扫帚 / 小罐头图标 → 协作动画 →「友情点 +10」 |
| 留言墙 | 客厅板子贴颜文字便签 |
| 特产交换 | 动森式交易弹窗（我的特产 ↔ 对方特产） |

示意：`docs/refs/scene-02-visiting.png`

---

### 场景 3：晒图广场与世界聊天（Social Hub）

**晒图广场（Photo Wall）**

- 双列瀑布流（Pinterest 风）。  
- 卡片 = 拍立得相框图 + 手写感文案 + 赞/评。  

**世界聊天（Chat Drawer）**

- 半透明底部抽屉，上滑可近全屏。  
- 气泡含宠物表情包；点头像可一键「前往串门」。  

示意：`docs/refs/scene-03-social-hub.png`

## 三、与工程实现的映射

| 设计模块 | 客户端 | 服务端（现状 / 规划） |
|----------|--------|----------------------|
| 家园 / Spine | `PetActor` + Main 场景 | pet feed/outfit API 已有 |
| 喂养滑动菜单 | HomePanel 扩展 | `/pet/feed` |
| 换装衣柜 | Outfit 抽屉 UI | `/pet/outfit` |
| 串门双宠 | Visit 场景 + 双 Skeleton | visit API 已有；需补访客进场表现 |
| 打扫/喂食协作 | Visit 互动按钮 | 可扩展 interact action |
| 留言墙 / 特产交换 | Visit 面板 | **二期或紧随一期补 API** |
| 拍照拍立得 | 截屏隐 UI | 本地相框；上传走 OSS **二期能力提前设计** |
| 晒图广场瀑布流 | Social Hub 场景 | **原二期；设计已纳入正稿** |
| 世界聊天抽屉 | ChatDrawer | WS 世界频道已有 |

> 产品说明：晒图广场 / OSS / 留言墙 / 特产交换在 [mvp-plan.md](./mvp-plan.md) 中标记为「设计已定稿，服务端分期落地」；一期可先做 UI 壳 + 本地拍照预览。

## 四、Cocos 场景节点建议

```
Canvas
├── RoomCamera (固定 2.5D)
├── RoomRoot
│   ├── BG_Floor / BG_Wall / BG_WindowLight
│   ├── FurnitureLayer
│   ├── PetHost (Spine + PetActor)
│   └── PetGuest (Visit only)
└── UIRoot (Widget 四角)
    ├── HUD_TopLeft / TopRight / SideRight
    ├── BottomActions
    ├── Panels (FeedSheet / WardrobeDrawer / VisitSheet)
    └── ChatDrawer / PhotoWall (Social)
```
